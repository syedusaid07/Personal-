# 💻 C Programming Post-Lab Tasks

Welcome to my repository! This section contains all the C programming tasks completed after my lab.

---

## 📂 Lab Programs List

* **`scholarship.c`**: Determines scholarship eligibility based on exam marks ($\ge 80$) or family income ($< 50,000$).
* **`library_fine.c`**: Calculates library fines dynamically based on late days using conditional logic.
* **`student_registration.c`**: Demonstrates full name input using `fgets()` and single-character input using `scanf()`.
* **`rectangle_area.c`**: Calculates and displays the area of a rectangle from user-provided dimensions.
* **`square_cube.c`**: Computes and prints both the square and cube of a given number.
* **`temperature.c`**: Converts temperature readings from Celsius to Fahrenheit.
* **`average.c`**: Calculates the average marks of three subjects.
* **`pass_fail.c`**: Evaluates whether a student passes or fails based on a 50-mark threshold.

---

### How to Run
1. Copy the code from any `.c` file in this branch.
2. Paste it into any online C compiler (like **OnlineGDB** or **Programiz**).
3. Run and test the output!
